## 🤖 AI 활용 개발 방식

코드 작성은 AI 코딩 에이전트(**Claude Code · Cursor**)에 맡기고, **요구사항·안전 조건 정의**와 **검증·머지**는 직접 합니다.

- 기능 1개 = 브랜치 1개 = PR 1개로 나누고, 커밋 메시지에 무엇을·왜 바꿨는지와 장비 동작 변화 여부를 남깁니다.
- 단위 테스트(MSTest)·시뮬레이션 모드·실장비 구동으로 확인한 PR만 머지합니다.
- AI가 쓴 코드라도 장비에서 돌아가는 결과의 책임은 저에게 있습니다.
